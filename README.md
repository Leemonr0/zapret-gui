# ZapretGUI

Нативный Windows GUI для [zapret](https://github.com/bol-van/zapret) (`winws.exe` + `WinDivert`) на базе стратегий [zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube) v1.10.4.

Один автономный файл `ZapretGUI.exe` (~1.8 МБ) — не требует установки и дополнительных папок. При первом запуске сам распаковывает `winws.exe`, драйвер `WinDivert`, 22 стратегии и списки доменов в `%LOCALAPPDATA%\ZapretGUI\runtime\v1.10.4\`.

## Возможности

- **Главная** — запуск и остановка обхода в один клик, время работы и PID, выбор области (`Всё сразу`, `YouTube`, `Discord и игры`, `Свой конфиг`), проверка реального TLS/HTTP-отклика (YouTube, Discord, Голосовой чат, Telegram), автоподбор рабочей стратегии, сторож соединения и игровой фильтр портов.
- **Пресеты и хосты** — переключение между 22 стратегиями `.bat`, встроенный редактор списков доменов и IP, режим `Эксперт` с предпросмотром и редактированием аргументов `winws.exe`.
- **Ускорение и DNS** — смена DNS адаптера (Cloudflare, Google, Quad9, AdGuard, Yandex, DHCP), очистка кэша DNS, включение `TCP Timestamps`, настройка диапазона портов игрового фильтра.
- **Диагностика и логи** — проверка прав администратора, службы `BFE`, драйвера `WinDivert`, файлов `winws.exe` и `TCP Timestamps`, очистка зависших процессов/служб и живой вывод `winws.exe`.
- **Настройки** — автозапуск как служба Windows, системный трей, интервал сторожа, язык `RU` / `EN`.

## Запуск

1. Скачайте [`ZapretGUI.exe`](ZapretGUI.exe) (или из раздела **Releases**).
2. Запустите файл и подтвердите права администратора (нужны для драйвера `WinDivert`).
3. Нажмите **Запустить обход** или **Подобрать стратегию**.

> Требования: Windows 10 / 11 (x64), встроенный Microsoft Edge WebView2 Runtime.

## Сборка из исходников

Не требует Visual Studio или .NET SDK — используется встроенный в Windows компилятор `.NET Framework 4.8` (`csc.exe`):

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\src\build.ps1
```
